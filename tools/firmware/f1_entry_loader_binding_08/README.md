# Loader08 fixed boundary-only observation

This independent default prep-only loader binds the exact new UI08 source and
97,000B authenticated observation SO, not any frozen UI07 module. Its own
496B publication is dynamically defined at VA 287208, in the file-backed RW
LOAD at file offset 90592/VA287200 (page relation 90112/286720).
The real UI08 runtime calls the bounded provider/Surface sampler after the
admitted original-first UI boundary. It installs selection but cannot obtain
an actual write token or enable a mask in this observation-only module.
Entry admission really constructs the added button/popup, subscribes its own
input/selection listener and mutates that private UI registry. Observation-only
means no native pixel/paint/token operation, not absence of these UI writes.

The marker is exclusively ui08.entry: IQ4_F1_UI08_ENTRY_OBSERVE_ONLY x y LF.
The new proof schema/profile, exact runtime/render source hashes and exact SO
hash must match. Existing actual RAM, baseline, scratch-inode restore, backup,
sole-controller, original environment/argv/umask and cold-recovery receipts
remain mandatory. Native text patch/provider lease/paint/mask authorization
are explicitly false. The original RAM restorer mechanics are reused, including
restoring the original runner inode before User exec, deadline restoration,
no hot unload, no process signal and no new native exit primitive.

The --entry-read route has no caller-provided PID/path/pointer. It opens only
the exact loaded User and own protected module, derives its LOAD mapping,
reads 496 bytes twice via O_RDONLY, requires matching even sequence and bytes,
then rechecks PID/start ticks/exe/inode/hash/maps. The saved-copy decoder accepts
only the boundary-only result states and never promotes Surface/getter scalar
candidates to complete source/write/lifetime qualification. Hardware origin is
validated by Root's actual controller, not by local JSON identity matching.

Default generation prints prep_only and an empty command plan. Enabled local
packaging needs a separately held actual new proof and two independent original
runner files; no proof or hardware fact is created by these build tools. The
six fixed public artifacts use the existing padding-free base64/octal-tail
242B bounded Sys stager. No Windows/SDK/device/network/target execution occurs
in this directory. The preview launcher is disabled; enabled branches are
compile-only ET_REL until actual proof is accepted.
