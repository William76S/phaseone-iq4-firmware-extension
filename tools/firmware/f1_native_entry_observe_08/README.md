# UI08 actual source caller and default OFF module

This independent runtime derives frozen UI07, preserving the original-first
pthread unlock call exactly once, errno, owner observation and BoundaryBridge.
After the actual admitted UI boundary has made the private entry Ready, it calls
the concrete frozen UI08Bridge, installs its selection consumer, and samples
the actual provider/Surface candidates into the new 496B own publication.
The protected marker is exclusively `ui08.entry`, canonical
`IQ4_F1_UI08_ENTRY_OBSERVE_ONLY x y\n`; old UI07 markers cannot enable it.

The new AArch64 SO is linked and statically inspected here, never loaded or
executed. The frozen 08 production callback/issuer and four-ratio render ET_REL
bodies remain separate: this observation link garbage-collects those unused
functions and makes no claim they are present in this SO. This runtime does not
configure any provider contract,
install a text hook, invoke a native blit or issue a PaintToken. BoundaryObserved
contains scalar candidates only; full source/write/lifetime remain unknown.
Active selection stays rejected until that separate actual write token exists.
Default OFF builds and actual new module identities remain independent of all
frozen UI07/Loader07 bytes. Loader08 must bind the exact new SHA and dynamic
publication location; no deployment or camera action is authorized here.

`build_prepare.py` verifies the two frozen source closures, mechanically derives
the finite runtime change, compiles only that target runtime, and links the
already-frozen old objects and new function-section compiles of exact 08 source. It checks export/undefined/import identities,
whole runtime disassembly, the actual boundary and selection definitions, the
actual 496B symbol and file-backed RW LOAD, and the existing exact strip proof.
It does not rerun old fixtures. The source/objects are host artifacts, not
runtime admission or provider ownership evidence. `freeze.py` and `validate.py`
bind the new source and review artifacts by complete bytes/hashes.
