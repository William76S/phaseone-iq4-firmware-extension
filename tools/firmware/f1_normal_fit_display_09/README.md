# Fixed-array normal-fit production module 09

This independent derivative retains the real producer, native post-return ABI,
selection consumer and four-ratio drawing body in an actual linked AArch64 SO.
Frozen 08 source, objects, SO identities and the two link refusals are unchanged.
The fixed planner replaces makeDrawPlan/std::vector with the same centered
full-source crop formula and four fixed non-overlapping bands. It admits only
zero-rotation normal fit and uses ceil(edge-.5) shared pixel-center edges with
fixed alpha 166 (the frozen .65 black opacity). No vector, heap allocation,
exception-constructor shim, alternate GCC sysroot or lround is used in this
production planner. The actual target object must lower ceil to AArch64 FRINTP;
all resulting dynamic imports are checked against the exact original libraries.

The new actual runtime preserves original unlock first/exactly once/errno and
calls UI09Bridge after admitted BoundaryBridge. Its independent ui09.entry
marker creates the added button/popup and subscribes the selection listener.
It samples the new 496B schema9 publication without a text hook; that is an
actual source caller for provider/Surface/normal-fit candidates. These UI
registry writes are distinct from the absent pixel/text/paint operations.

The production ProvenProviderAdapter and Renderer are retained in the SO,
including the native RGB24 zero-rotation return branch, frame/Surface/source
binding and callback-local private PaintToken. The actual provider lease
contract remains Unknown and there is no text installer or automatic issuer
call. Root still needs independently reviewed actual inline provider ownership,
complete write facts, near mapping, thread quiescence, atomic instruction/cache/
unwind/unpatch and retained module lifetime before any production dispatch.
Default OFF never calls a getter/present, native blit, pixel fill or source
acquire/release. The runtime does not configure that provider contract.

Original stock writes must clean prior own pixels before hide/OFF/redraw.
After actual clean stock coverage and a zero-band plan, pending restoration
coverage clears; dirty shrink or unsupported rotation cannot borrow a border
rectangle as complete interior restoration. Root can keep this first model at
fixed normal fit and require closing the mask before an unsupported operation.

Host checks run the 11 finite owned state/producer fault groups normally and
under ASan/UBSan, plus 270 fixed plans compared to the frozen vector geometry
over four ratios/OFF, source shapes, offsets and small/large display extents.
These are owned fixtures, not camera receipts. AArch64 linking/static inspection
must confirm real producer/render definitions, own symbol closure, exact new
publication/LOAD identity, import providers and unchanged loaded-range strip
proof. Actual module loading/UI/source/write/lease/mask qualifications remain
false, as do the independently preserved strict startup failures. No SDK,
Windows, network, camera, target EXE or SO is executed by these tools.
