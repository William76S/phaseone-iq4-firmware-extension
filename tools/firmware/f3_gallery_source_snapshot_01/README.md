# Actual selected catalog source snapshot 01

The production factory binds the fixed original mutex guard constructor/dtor
and native-thread getter after double original-prefix checks. It snapshots the
actual IFM+1b0 vector's40-byte indexed file record under the original IFM+5f8
recursive mutex, then returns the selected SD/XQD LinuxFS, bounded actual folder,
ASCII case-preserving IIQ leaf and SourceDeps process-lifetime inputs. It does not
call the original mutable shared Reader/filesystem setter or guess a gallery path.

Actual IFM must come from the original outer-IFM selection/executor chain; index
is the original typed selected-image getter's value. File flag and location bits,
count/capacity/end bounds, exact FS vtable and original Reader dependencies are
checked. Leaf is the original finite13-character catalog field, `.IIQ` or `.iiq`;
no slash/dot traversal. Nonmatching arbitrary imported names remain unsupported.

The original mutex can only be locked on an actual original CThread. A foreign
owner refuses before lock; original guard constructor/dtor each execute once.
Exception, unexpected depth/owner or dtor failure retains the8-byte nonmoving
guard permanently. Recheck is another actual short lock/snapshot after enqueue;
this object alone does not pin encoded RAW contents. The worker must open an own
read-only Reader and prove its same actual held FD, source content and card lease.

`python3 tools/firmware/f3_gallery_source_snapshot_01/build.py` passes13 normal and
13 ASan/UBSan catalog/mutex fixtures with the production SourceDeps02 hook check;
the native mutex and memory owner are explicit host fixtures. Two target objects
are compiled, not executed. Final linking requires SourceDeps02 in place of01.
