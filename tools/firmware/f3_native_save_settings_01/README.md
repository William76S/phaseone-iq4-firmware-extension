# Native save-settings finite static contract 01

Read-only original-User evidence for the actual File Settings root, native SD storage/JPEG events, and the new-capture RAW fanout/retirement boundary. This is neither a firmware patch nor a global JPEG-only implementation. It does not execute target code, load an SDK, or communicate with a device.

Run `python3 tools/firmware/f3_native_save_settings_01/collect.py --output /absolute/fresh/output` from the project root. The original User whole SHA and ELF mapping are checked before extracting finite instruction windows, table records, resource pairs, and direct-call inventories. The inventories explicitly do not prove absence of indirect/alias paths.

The corresponding `analysis/firmware/f3_native_save_settings_static_01/REVIEW.md` and `CONTRACT.json` distinguish observed original semantics from proposed capture-transaction integration. The UI extension site is a real SubMenu append; existing IIQ File Format and SD JPEGOnly enum tables retain their original meanings.
