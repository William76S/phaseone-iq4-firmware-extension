# Checked saved SD RAW producer 01

This is a local AArch64 source/build result, not a camera acceptance result. It binds the stock User SHA `9b611efe64067685b770ba3984ae951684c5a401f73f77a03b316be374032cdb` and the four exact sites in `ORIGINAL_BINDINGS.json`.

The acquired-node wrapper replays `STR manager+0x48=node` once, preserves the caller's integer/SIMD registers and flags, and branches back to `0x8dc4c4`. It supplies an identity ticket before the existing RAW fanout. The original SD writer's seven-argument call still runs once. Only the matching writer opens its new public RAW through exclusive `openat`; it binds that descriptor into the real stock File using the recovered original function. A checked native close, successful writer return, whole-file SHA/EOF and stable inode/metadata are all required before the synchronous saved consumer is called. The independent read descriptor, selected SD request and shared activity ticket remain held throughout that consumer.

`f3_capture_install_native_01(memory, saved, context)` supplies the actual Card06 superset of Card05, original syscall ports and the synchronous consumer. The consumer runs on the existing SD native task thread; no ordinary pthread is introduced. It must return 1 only after its actual render/source/reader/arena/file cleanup. UNKNOWN retains the card, descriptors, receipt and activity ticket. The original checked writer descriptor belongs to the stock File until checked close returns. No retry/force-close is offered.

This stage never removes RAW. A failed writer may leave a partial new file; preservation is not proof of a complete RAW. The original outer SD task ignores the nested writer result at `0x8e0638`, so its completion byte is not accepted as a full RAW receipt. XQD auto export/deletion is not claimed: its separate close path has not met this checked-close contract. Existing IIQ files are never adopted as owned captures and are never overwritten; EEXIST refuses this writer rather than falling back to O_TRUNC.

Integrate exactly one `native_activity_01/activity.o` and the Card06 objects (not Card05 and Card06 together). The `B` acquisition hook is not interchangeable with a `BL` call hook. `f3_capture_status_01` exposes borrowed own storage only to its serialized owner or after stopping; it is not a lock-free UI publication. SourceDeps01, Source01, render02, export04 and coordinator06 must supply actual full RAW decode and checked JPEG completion; this producer alone does not prove decoded pixels or JPEG completion.

Local reproduction: `python3 tools/firmware/f3_saved_raw_capture_01/build.py`. It verifies the input User/toolchain, runs 13 real host-file fault cases normally and under ASan/UBSan, and cross-compiles five AArch64 ET_REL objects without executing them. `BUILD.json` preserves every actual command/result, undefined symbols and relocations. `collect_static.py` preserves the finite original caller/function/table windows. No SDK, camera or target ELF is run.
