# Automatic full RAW capture: SD and XQD producer03

This local source replaces three objects in Capture01/Runtime02. The original RAW acquisition assembly and directory ports remain unchanged. RAW selection delegates the original storage functions. The backend capability mask is 1 for SD and 2 for XQD, exposed only after the actual native factory's double-read code/table checks and successful configuration. Card presence and writable mounts still require Card06 acquisition.

`Snapshot06` is read once at the exact acquired-node boundary. SourceDeps02 captures actual original Reader dependencies at that boundary. Only the exact original live Store argument for that immutable node can join the group. An early source snapshot is rechecked later; no worker relies on a mutable current-node pointer or retains the raw vendor node after the original call.

The original fanout predicate is called once at `8dc4ec`. Main and context constructor bytes prove weight 4 is SD and 2 is XQD; only native-selected cards with JPEG requested enter the actual group mask. The original SetRefs at `8dc634` runs once before the group is sealed. The activity lease stays with the process-lifetime group until all its actual selected callbacks have normally ended. It is never released by the IFM executor. Card06's process-wide task owner is acquired serially on each original native storage thread, with a 600-second kernel-monotonic observation budget. A second card never treats BUSY as permission to borrow the first card's lease. The ticket, node identity, group lease, mask and dependency snapshot are rechecked after the serial CAS. No thread or SDK instance is created here.

XQD's `8df19c(storage,node,filename)` first builds an IIQ using the embedded RAM filesystem at `storage+2c8`. Its first checked writer close therefore is not a card-file completion. The final Linux card filesystem is `storage+2c0`, opened at `8df6b8`. Our final open creates the actual public RAW exclusively, with `O_DIRECT|O_WRONLY|O_CREAT|O_EXCL|O_NOFOLLOW|O_CLOEXEC`, omitting the original destructive TRUNC. This preserves the original direct writer's alignment and initial position zero. The held read descriptor is an independent non-direct descriptor for the same newly created inode. Failed EXCL never falls through to stock TRUNC. A filename/shape outside the limited capture grammar before any own file/directory creation follows the stock RAW open and skips own JPEG conversion.

The original final XQD File destructor at `8df8e8` and its unwind counterpart `8df940` both use one wrapper. It calls the real `82580c` bool close at most once. That native close clears File+14 before calling filesystem+e8; a cleared byte alone cannot prove close success. Only returned true plus a live closed-shape read permits the stock destructor's no-I/O closed branch. A false/exception becomes permanent Hold and neither later unwind nor destructor retries native close. The File is stack storage; no Store-return, saved proof or worker reads its address after destructor completion. The stable independent read FD, card and activity remain owned on unknown outcome.

A returned successful original Store, checked final close, stable public inode, full-file SHA256, exact EOF and directory sync precede the synchronous coordinator callback. The original SD path receives the same checks through its existing native writer close. SD and XQD write from the original memory payload/metadata into their own filesystem and File; neither reads the peer card's IIQ. Per-card exclusive creation and held-FD identity prohibit adopting an existing or peer inode. JPEG-only deletion remains coordinator08's separately checked per-card operation after publication and actual render/source cleanup; producer03 never deletes RAW. Manual existing IIQ remains outside this producer.

`f3_capture_saved_proof_03` approves only one of two own static slots and exact group/card/sequence/activity membership. `f3_capture_dependencies_03` returns the acquired dependency snapshot only after the saved proof, original dependency recheck, and another saved proof. Failure before own resources preserves the stock RAW path; unknown with live owners retains them and excludes subsequent own work. No timeout cancels a native call, no forced close, no reset, and no retry exists.

Build locally with:

```
python3 tools/firmware/f3_saved_raw_capture_03/collect_static.py
python3 tools/firmware/f3_saved_raw_capture_03/build.py
python3 tools/firmware/f3_saved_raw_capture_03/freeze.py
```

Target ELF, SDK, Windows and camera execution are absent.
