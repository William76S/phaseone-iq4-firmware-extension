# UI counter + independent FD198 supervision, source 03

Independent derivative of frozen Bootstrap02 and RAMEntry02. Neither original is edited. Default entry `F4_ENABLED=0`; there is no enabled generator or staging plan. Run only the SDK-free own-code host tests/build inspector `python3 -B tools/firmware/f4_ui_supervision_03/build_validate.py`. It never executes target SO/entry or opens a camera.

The separately reviewed counter launcher connects the independent supervisor, performs `F4L3\n` / `F4OK3\n`, then execs original User retaining identical PID/start ticks and owned seqpacket FD198. Constructor verifies peer root credentials and expected entrytool path, reports Loaded and Disabled/Rejected or Waiting without calling UI. Only existing exact actual UI boundaries/control callbacks report Queued, Attached, Detaching, DetachedEventRetained/Hold. Each unmodified native unlock remains exactly once and first; reporting uses one nonblocking MSG_NOSIGNAL send per phase, no retry. Failed IPC cannot cancel original detach or alter return/errno.

The fixed 64-byte LE wire has strict sequence/phase/length/reserved/count bounds, at most eight messages. Supervisor verifies original launcher-to-User process identity/ticks before every received packet, saves exclusive bounded per-phase JSON, and never interprets pointers/PIN/RAW. Counts are merged notifications, never source FPS. A successful terminal message means observers detached at the checked later UI boundary; complete native event/global registry nodes/SO remain alive until stock process exit. No hot unload is claimed.

At deadline/disabled/invalid/missing phase, restore original runner and preserve originals/status. Never signal/kill User, unregister from another thread, invoke arbitrary addresses, force module unload or invent success. Root must separately verify actual source/role/hash, runner dual originals, current whole User hash/exe/PID, whole EEPROM doubles, mounts, stock exit/respawn/coldboot restore and single controller before any enablement. Full User byte export becomes mandatory if modifying User; this counter-role source changes RAM runner/new files only.
